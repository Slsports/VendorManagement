When the LS import found several names that looked like one vendor, it merged them and asks you to confirm.

## How to
1. Open **Review queue** and find **Merged at import**.
2. The card lists the LS names that were joined and their routes.
3. If it is one vendor, optionally set the route, then click **Yes, one vendor**.
4. If one name is really a different vendor, click **No, split one out**, choose the name in **Which name is a different vendor?**, optionally set the route, and click **Split it out**.

## Good to know
- Confirmed merges show on the **Lightspeed merge report** as things to do in LS.

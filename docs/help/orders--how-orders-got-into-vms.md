Most orders in VMS were loaded from Dana's spreadsheets. New ones are added by hand or from email.

## The spreadsheets
- **Seasonal Buying Guide** (the Summer WWD Order Guide, built from the Placed Order Summary): the first load, with the Open, Entered and Paid tabs. Vendors were matched by name (sheet spellings saved as other names for the vendor) and a few missing vendors were created and flagged to check.
- **Placed Order Summary v2.0**, tabs 1 to 4 (Open, Entered to Pay, Paid, Cancelled): refreshed the orders already on file and added about 200 new ones.

## Good to know
- Loading a sheet again updates the same orders; it does not make copies. Rows typed twice on the sheet count once.
- Anything changed in VMS (a date, cost, status, note) is kept when the sheet is loaded again.
- Each WWD order got a show tag from its date. A "?" means the show was guessed.
- Extra columns from the sheet show on the order under **Also on the sheet**.
- The tag beside the status on an order says where it came from: placed order summary, order guide, email, or none for orders typed in.
- Loading a sheet is done by Claude on Dana's request; there is no upload button for it.

Some vendors' items are easier to find when the Vendor ID is added to the end of the item name, like NAME [Vendor ID]. You can turn this on or off for one order or one item.

## How to
1. Open the order and go to **Check-in pricing**.
2. Tick or untick **Add Vendor ID to item names** to change it for the whole order.
3. To change one item only, click the small **[ID]** button beside its name. A crossed-out [ID] means the Vendor ID is left off.

## Good to know
- Each order starts with the vendor's own setting (set on the vendor's edit form). The note beside the tick box says whether it follows the vendor or was changed for this order.
- An item changed on its own shows an amber ring around its [ID] button.

If a file landed in the wrong folder or year (for example Claude filed it wrong), move it.

## How to
1. Open the vendor's page, find **Documents** and open the folder.
2. Click **Move** under the file's name.
3. Pick the new **Folder** and **Year**.
4. Click **Move**.

## Good to know
- The folder you moved it to opens so you can see it.
- Moving a file into **Confirmations** or **Invoices** starts Claude's check against the order. Moving it out sets an unfinished check aside.
- In an email, the green "Saved to …" tag on an attachment opens the same Move box.

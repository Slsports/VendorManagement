Move an order to its next step, for example when it ships, arrives or is paid.

## How to
1. Open the order (click its date on the **Orders** list or on the vendor's **Order history**).
2. At the top right, open the status box (it shows the current status).
3. Pick the new status. It saves right away and a short message confirms it, e.g. "Now received".

## Good to know
- The change is added to the **History** box on the order with today's date.
- You can pick any status, forward or back, if one was set by mistake.
- A status you change in VMS stays when the Placed Order Summary is imported again.
- Viewers can see the status but cannot change it.

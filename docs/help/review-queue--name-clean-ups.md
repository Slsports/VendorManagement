Some LS vendor names carry a rep or parent-company tag. VMS proposes a cleaner name for each.

## How to
1. Open **Review queue** and find **Name clean-ups**.
2. Each card shows the proposed name, any rep group, and any alias it keeps.
3. Edit the name in the box if you like, then click **Use this name**. Or click **Keep as is**.
4. To accept every proposal at once, click **Apply all as proposed** at the top of the group and confirm.

## Good to know
- The old LS name always stays as an alias, so imports and mail still match.
- Nothing changes in LS itself.

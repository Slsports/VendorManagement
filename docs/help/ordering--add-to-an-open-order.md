When a sales report shows we need more of something and the vendor already has an order of ours that has not shipped, we can add to that order instead of placing a new one. Whether an order can take add-ons depends on the order (a pre-order placed months ahead usually cannot), so each order carries its own choice.

## How to
1. On the order's page, set **Add-ons**: **Yes until it ships**, **No**, or **Ask the rep**. Blank means nobody has said. **Ask the rep** drafts the one-line question from orders@; set the answer when it comes back.
2. Every sales report now shows **ON ORDER** and **NEED AFTER ORDERS** next to NEED, with the order and its ship date in Notes ("12 on PO SLS101426, ships Nov 3"). Where the order is marked Yes, the note says "add to PO SLS101426"; otherwise "add-ons not confirmed".
3. In the **Suggested order**, fill in the Order quantities and click **Add to PO SLS101426** (it only shows for orders marked Yes). The items go on that order as add-on lines, marked with the day, and the email opens: the add-on items in one table, the original confirmation attached as it is, and a request for one confirmation covering the whole order. If no confirmation has come back yet, the email says so and lists the original order too.
4. Send it. The order goes back to **Awaiting confirmation**; the confirmation check then compares the new confirmation against the whole order, add-ons included.

## Good to know
- A shipping notice or invoice on the order turns **Yes** to **No** on its own.
- If the rep says no, place the add-on as a new order with **Order placed** as usual.
- Orders with no item list in VMS are named at the top of the report's Flags tab so you can check them by hand.

The **Item names** page checks every active Lightspeed item name against Trevor's naming SOP (SOP-INV-001-NC) and lets you fix them. VMS makes the change in Lightspeed for you.

## How to
1. In the menu, click **Item names**.
2. Pick a tab:
   - **Quick fixes**: capitals, spacing, marks and approved shorthand (YOUTH to YTH, GREY to GRAY, SMALL to SM), and a dash or # in front of the Vendor ID (SET - 9869 becomes SET 9869). No new shelf tag needed.
   - **Vendor ID**: the Vendor ID goes last for Fishing items and for Coghlans, World Famous Sports, Lazy One and Ty, and comes off for everyone else.
   - **Needs a look**: things VMS cannot fix on its own, like the order of the parts, a name over 52 characters or two items with the same name. Type the new name in the box.
3. Narrow it with the vendor, category or search boxes if you like.
4. Tick the names you want, or change any new name in its box.
5. Click **Approve and send**. To keep a name the way it is, click **Leave as is** instead.

## Good to know
- Names go to Lightspeed within a few minutes. **Send now** at the top sends the waiting ones right away.
- VMS reads each item in Lightspeed first. If someone changed the name there in the meantime, it does not overwrite it. The item shows under **Sent / waiting** with what it found.
- Any * or ** at the start of a name stays exactly as it is.
- A name another Lightspeed item already has is never sent. Add what tells them apart (size, color, pack count).
- **New shelf tag** means the change alters what the name says. Those names go on Trevor's task **Print new shelf tags**, due in 7 days and listing every item, so the tags get printed and replaced at each store.
- **No new tag** changes (capitals, spacing, shorthand) don't need a new tag.
- **Take back** on the **Sent / waiting** or **Left as is** tab undoes a choice that hasn't gone to Lightspeed yet.
- Rentals, labor, marina fees and deposits are not checked.
- Lightspeed needs Full access (Settings › Lightspeed).

Each person's signature is added under every email they send from orders@ through VMS.

## How to
1. Open **Settings** and click **Mail**.
2. Find **Signatures**. There is a box for each person.
3. Type the signature (for example name, Shaver Lake Sports, phone).
4. Click **Save** under that box.

## Good to know
- **Save** only appears once you have changed something.
- VMS confirms "Signature saved for …".

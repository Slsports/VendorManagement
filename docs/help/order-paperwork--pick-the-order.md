When Claude cannot tell which order a confirmation or invoice belongs to, it asks "Which order is this for?". You pick it.

## How to
1. Open the check (it shows **Which order is this for?** on the Dashboard card).
2. Open **Choose an order**. The vendor's orders are listed newest first with date, PO, cost and what was ordered.
3. Pick the right one and click **Use this order**.
4. Claude compares it right away.

## Good to know
- If the paper is not filed to a vendor yet, the box says **File the vendor first**.
- If it does not belong to any order, use **Not a confirmation: set aside** (or the invoice version).

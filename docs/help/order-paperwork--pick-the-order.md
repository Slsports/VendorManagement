When Claude cannot tell which order a confirmation or invoice belongs to, and there's no sales report to compare it with, the check shows **No order found: which order?** in the Review queue. You pick it.

## How to
1. Open the check (it shows **No order found: which order?** in the Review queue and on the Dashboard).
2. Open **Choose an order**. The vendor's orders are listed newest first with date, PO, cost and what was ordered.
3. Pick the right one and click **Use this order**.
4. Claude compares it right away.

## Good to know
- A confirmation Claude compared with the sales report (no order in VMS) also lets you pick the order if there is one.
- If the paper is not filed to a vendor yet, the box says **File the vendor first**.
- If it does not belong to any order, use **Not a confirmation: set aside** (or the invoice version).

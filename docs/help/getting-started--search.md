The search box at the top of every page finds a vendor as you type.

## How to
1. Click in **Search vendors, orders, invoices…** at the top of the page.
2. Start typing part of the vendor's name or one of its other names (aliases), like "WWD" for Worldwide. Up to 8 matching vendors drop down.
3. Click the vendor, or use the up and down arrow keys and press Enter. The vendor's page opens.

## Good to know
- A vendor whose name or other name is exactly what you typed comes first (WWD brings up WORLDWIDE first), then names that start with it. Inactive vendors show in grey, marked "Inactive vendor", below active ones.
- The vendor boxes on other screens (when you pick a vendor for an order or an email) find vendors the same way.
- The last line, **Search everything for "…"**, opens the Search page. Searching orders, invoices and files from there is not ready yet; for now use the search box on the Orders or Mail page.
- On a phone the box is a magnifying glass; see "Use VMS on a phone".
- Invoice Uploads logins do not have the search box.

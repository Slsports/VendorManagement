**File Manager** is in the menu but is not built yet. It will show every document in one place: browse by vendor or order, preview, download and tag.

## How to
1. For now, open a vendor's page and use its **Documents** box.
2. To bring in many old files at once, use **Vendors**, then **Bulk import documents**.

## Good to know
- Nothing is lost: every file lives in its vendor's Documents.

Tagging says what a task is about, so it shows on that vendor's, order's or email's page and links back to it.

## How to
1. In the task, open the **About** list.
2. Pick **Vendor**, **Freight company**, **Rep group**, **Order** or **Something else**.
3. Choose it from the list (for **Something else**, type a word or two such as "Marina dock" and click **OK**).
4. Add more tags the same way. Remove one with the **x** on its tag.

## Good to know
- For **Order**, tag the vendor first to see all of that vendor's orders; otherwise you see open orders.
- Email tags come from the **Task** button on an email.
- Tasks tagged to a vendor, order or email are listed in a **Tasks** box on that page.

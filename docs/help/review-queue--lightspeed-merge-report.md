Vendors merged in VMS still need merging in LS by hand. This report lists each one so you can do it and tick it off.

## How to
1. Open **Review queue** and click **Lightspeed merge report** at the top.
2. **To do in LS** shows confirmed merges not yet done there; **Everything** shows all merges.
3. Each box shows the name to keep in LS and the names to merge into it.
4. After merging in LS, tick **Done in LS**.
5. Click **Download CSV** for a spreadsheet of the list.

## Good to know
- Merges still waiting in the review queue show as **Awaiting your OK**.
- Names that exist only in VMS say "nothing to do in LS".

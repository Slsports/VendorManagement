Some reps write up the order in a spreadsheet for you to agree to, then send it on to the vendor (Maryellen does this for Planet Cotton). That spreadsheet is our order, so VMS files it that way.

## How it works
1. On the vendor's **Edit** page, the rep's email address is under **Their order sheets are our order: spreadsheets from**.
2. A spreadsheet from that address (or forwarded from it) goes to the vendor's **Our orders** folder, not Confirmations or Show specials.
3. When the email's conversation is tied to an order, the sheet goes on that order too. The vendor's confirmation is then checked against it.

## Good to know
- Only spreadsheets count (Excel, CSV). Pictures and PDFs from the rep are filed as before.
- If a sheet is not on an order yet, attach it from the order's **Documents** box (**Attach**, type **Our order**).

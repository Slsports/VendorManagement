If a file is not really a confirmation or invoice, set its check aside. If a check was closed by mistake, reopen it.

## How to set one aside
1. Open the check.
2. Click **Not a confirmation: set aside** (it says invoice for an invoice).

## How to reopen
1. Open the check from the order's **Paperwork** box.
2. Click **Reopen**. It goes back on the list to review.

## Good to know
- Set-aside checks no longer show in the order's Paperwork box or on the Dashboard.
- Moving the file out of the Confirmations or Invoices folder on the vendor page also sets its unfinished check aside.

Rules only run when a review item is created. Run them over the items already in the queue after adding or changing a rule.

## How to
1. Open **Settings** and click **Review assignments**.
2. Under **Items already waiting**, tick **Also re-assign items someone already has** if you want those moved too.
3. Click **Apply rules now**.

## Good to know
- VMS says how many items were assigned, or "Nothing to change".
- Without the tick, only unassigned items are given out.

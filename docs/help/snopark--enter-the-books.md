Every book has a number on its cover, and the permits inside run in order. Enter the books when the FedEx box arrives, so VMS knows which permit numbers are in each one. Later, the monthly report only needs to know which books are empty.

## How to
1. Open **Sno-Park** in the menu and click **Add books**.
2. Pick **Day permits** or **Season permits**.
3. Type the **First book number** as printed on the cover (like B450), **How many books** came, **Permits in each book** (25 in a day book, 10 in a season book, change it if the State changes it) and the **First permit number** (the first permit in the first book).
4. Check the line under the form: it says which permit numbers the books will cover. Click **Add books**.
5. Do the same for the other kind if both came in the box.

## Good to know
- VMS numbers the rest of the books and permits in order. Next time, the form suggests the next book and permit number after the last one entered.
- A book entered by mistake can be removed with **Remove** while it is still on hand. A book that is on a report cannot be removed.
- VMS refuses a book whose number or permits overlap one already entered, so the same box cannot be entered twice.
- The **Books** table shows every book this season: on hand, on a report, or returned, with the report it went back with.

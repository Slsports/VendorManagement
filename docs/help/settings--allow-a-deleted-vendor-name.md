When a name is deleted from the review queue as "not a vendor", imports skip it from then on. If that was a mistake, allow it again.

## How to
1. Open **Settings** and click **Organization**.
2. Scroll to **Deleted as not a vendor**. Each name shows the date it was deleted.
3. Click **Allow again** next to the name.

## Good to know
- After that the name can be added or imported again.
- "None yet." means nothing has been deleted this way.

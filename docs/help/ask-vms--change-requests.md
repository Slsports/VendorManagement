Only Dana decides how VMS works. If you'd like VMS to do something differently, like a new column on a report or a new button, tell Ask VMS, and it sends your request to Dana.

## How to
1. In an Ask VMS chat, say what you'd like changed and why, for example "Can the sales report show the Need column next to Order? It would save me a step."
2. Ask VMS sends it to Dana as a change request. Nothing changes yet.
3. Dana gets a task, **Change request from (your name): …**, that opens **Ask VMS › Change requests**.
4. Dana clicks **Approve** or **Turn down** and can add a note.
5. You get a task with her answer: **Your change request was approved** or **was turned down**, with her note.

## For Dana
- **Ask VMS › Change requests** lists everyone's requests, waiting ones first. **Open the chat** shows the conversation it came from.
- An approved request is built when you ask for it in your own Claude chat. Once it's done, click **Mark built**.

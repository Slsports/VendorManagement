Filing puts a conversation on a vendor's page. Most mail files itself; use this when it did not, or chose the wrong vendor.

## How to
1. Open the conversation.
2. Click **File to a vendor** (or **File to another vendor** if it is already filed).
3. Type the vendor name and pick it.
4. If the vendor is new, pick **+ Add new vendor** at the top. The form is filled in from the sender; check it and save.

## Good to know
- To find mail that is not filed, tick **Not filed to a vendor** on the Mail page.
- An inactive vendor shows grayed out; picking it asks to reactivate it.
- Once filed, the conversation shows on the vendor's page, and **Add order from this email** and **Save to documents** appear.

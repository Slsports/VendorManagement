VMS files each incoming email to its vendor without anyone doing it, and asks when it is not sure.

## How to
1. Nothing to do. Mail from a known sender is filed within a few minutes.
2. If an email lands unfiled or on the wrong vendor, open it and click **File to a vendor** (see "File an email to a vendor").
3. Unknown senders are asked about once, in the Review queue (see "Who is this mail from? cards").

## Good to know
- VMS looks at the sender's address first (a company address naming a vendor or rep group), then the subject, the body and file names for a vendor name or a PO number.
- Mail from a rep group files to the line it names. Mail naming none or several stays unfiled.
- Services like Bill.com, Faire or Worldwide file each email by the vendor it names, and tag every vendor named.
- When it is unclear, VMS never guesses: it waits for a person.
- Mail filed to a vendor later catches up on its own (files saved, tags added).

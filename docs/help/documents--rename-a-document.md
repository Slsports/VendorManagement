Give a file a clearer name in VMS.

VMS names paperwork on its own when it arrives: what it is, its number, the vendor's own name for it and the date, for example **Confirmation – SO-88198 – Feb 28, 2026**. This covers confirmations, invoices, credits, our orders, shipping papers and payments.

## How to
1. Open the vendor's page, find **Documents** and open the folder.
2. Click **Rename** under the file's name.
3. Type the new **Name** and click **Save**.

## Good to know
- When VMS reads the invoice or confirmation number later, it adds the number to the name.
- A file you rename keeps your name. VMS doesn't change it again.
- Moving a file out of the paperwork folders gives it back the name it came with.
- This changes the name shown in VMS only. The original file name still shows under it, in gray, and the file itself is unchanged.
